About Astro AI Processor

Astro AI Processor is a desktop application for processing and analyzing astrophotography images. It combines traditional image-editing tools with astronomy-specific analysis and optional AI-powered processing tools.

Who is Astro AI Processor for?

Astro AI Processor is intended for astrophotographers and astronomy enthusiasts who want to edit astronomical images and use astronomy-focused analysis in one desktop workflow.

What can it help with?

The application brings image adjustments such as levels, curves, histogram, crop and rotation together with FITS image support, FWHM and SNR analysis, background-noise analysis, astronomical plate solving, star processing, denoising and image mosaics. Optional 3D FLY tools can render an animation from prepared image layers.

How does Astro AI Processor use AI?

Optional integrations include StarNet++ for star removal, deepSNR for denoising and a local Altair assistant that uses a GGUF language model. These integrations may require separately installed tools or model files. Astro AI Processor is a desktop astrophotography image-processing application, not a general-purpose AI processor.

Technology and availability

The project is built with Python, PyQt5, OpenCV and NumPy, with astronomy and image-analysis libraries listed in its requirements. Astro AI Processor supports Linux and Windows; the product page currently links to a Linux download. The source code is licensed under the GNU General Public License v3.0.
