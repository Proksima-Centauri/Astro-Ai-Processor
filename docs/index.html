Astro AI Processor Documentation

This documentation covers Astro AI Processor, a desktop application for processing and analyzing astrophotography images. It describes the application's available workflows and optional external tools.

Getting started with Astro AI Processor

Install the Python requirements for a source checkout, or use a packaged build. Open an astronomical image, make image adjustments, optionally run analysis or astronomy tools, then save the result. The project supports Linux and Windows. See the Astro AI Processor installation instructions.

Astrophotography image processing

Astro AI Processor includes levels, curves, histogram controls, blur, crop, rotation and color adjustments. It also supports layers and an edit history with undo and redo.

FITS image support

Astro AI Processor supports astronomy FITS files with .fits, .fit and .fts extensions. The application also handles PNG, JPG and TIFF images.

AI tools in Astro AI Processor

Optional AI tools include the Altair assistant using a local GGUF model, StarNet++ integration for star removal and deepSNR integration for denoising. External command-line tools and model files must be installed separately where required.

Astro Upscale is a separate, non-generative resampling tool. It enlarges image data using Lanczos or bicubic interpolation rather than generating new detail.

Astronomical plate solving

Astro AI Processor can use the local solve-field command or the Astrometry.net service for astronomical plate solving. Local plate solving requires solve-field and its supporting data; the online service requires an internet connection.

Star processing

Use Star Shrink to reduce star size in an astrophotography image. StarNet++ can provide star removal when its command-line application is installed and configured.

Astrophotography image analysis

Astro AI Processor provides image and star analysis that includes FWHM, SNR and background-noise measurements. Plate solving can add astronomical field identification and coordinates.

Saving and export

Save processed images using the application's Save or Save As workflow. Supported image formats include PNG, JPG, TIFF and FITS; available output options depend on the selected format.

3D FLY guide

The optional 3D FLY workflow builds a video animation from prepared image layers. Read the Astro AI Processor 3D FLY guide for the complete step-by-step instructions.
