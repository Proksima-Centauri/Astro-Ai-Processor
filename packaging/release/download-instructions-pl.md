# Astro AI Processor - instalacja Linux (1 klik)

1. Pobierz plik `astro-ai-processor_0.1.0_amd64.deb`.
2. Kliknij pobrany plik dwa razy.
3. Otworzy sie Instalator oprogramowania - kliknij `Zainstaluj`.
4. Po instalacji uruchom `Astro AI Processor` z menu aplikacji.

Weryfikacja pliku (opcjonalnie):

- pobierz `SHA256SUMS.txt`,
- porownaj sume SHA256 pobranego pliku z wpisem w tym pliku.
